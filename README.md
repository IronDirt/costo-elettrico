# ⚡ Costo Elettrico

Strumento web per calcolare i costi elettrici dei tuoi apparecchi domestici. Tutti i calcoli vengono eseguiti localmente nel browser, senza bisogno di installazioni o connessioni a server.

## Funzionalità

- **Aggiungi apparecchi** — inserisci nome, potenza (W o kW) e ore di utilizzo al giorno
- **Calcolo costi multipli** — visualizza il costo per minuto, ora, giorno, settimana, mese o anno
- **Valuta configurabile** — supporto per CHF (Franco svizzero) ed EUR (Euro)
- **Tariffa personalizzata** — imposta il prezzo per kWh del tuo fornitore
- **Statistiche** — consumo totale, costo mensile/annuale, apparecchio più costoso, emissioni CO₂ stimate e costo medio orario
- **Modifica inline** — modifica i dati degli apparecchi direttamente nella tabella
- **Salva/Carica configurazione** — esporta e importa la lista degli apparecchi in formato JSON
- **Responsive** — interfaccia ottimizzata per desktop e dispositivi mobili

## Utilizzo

1. Apri il file `index.html` in qualsiasi browser moderno (non è necessario alcun server)
2. Configura la valuta e il prezzo per kWh nelle **Impostazioni**
3. Aggiungi i tuoi apparecchi con nome, potenza e ore di utilizzo giornaliero
4. Seleziona il periodo di visualizzazione (giorno, mese, anno, ecc.) nella barra in alto
5. Consulta le **Statistiche** per una panoramica completa dei consumi

## Tecnologie

- HTML5, CSS3, JavaScript vanilla
- Nessuna dipendenza esterna
- Funziona completamente offline nel browser

## Demo

Basta aprire `index.html` nel browser — non è richiesta alcuna configurazione.
